# Screen Time and Sleep Patterns

A 30-day observational study of mobile-device use and sleep patterns among university students.

## Objective

Examine associations between screen time, application use, and sleep-related indicators.

## Approach

1. Collect daily screen-time and sleep observations.
2. Compare usage patterns and sleep measures across participants.
3. Analyze correlations and interpret observed trends.

## Project evidence

[Read the project report](WSME%20REPORT.pdf)

The analysis describes associations within the collected sample; it does not establish causation or population-wide conclusions.

**Methods and skills:** Data collection · observational analysis · correlation · human factors
