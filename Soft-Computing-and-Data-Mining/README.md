# Weather Prediction with Neural Networks

An academic ANN project exploring geographical and time-dependent patterns in weather data.

## Objective

Use country, date, and time inputs to estimate temperature, humidity, and feels-like temperature.

## Approach

1. Prepare data and select input features.
2. Develop and train an artificial neural network.
3. Evaluate predictions across geographical and temporal settings.
