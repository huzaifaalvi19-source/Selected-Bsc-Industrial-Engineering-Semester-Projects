# Smart Weather Forecasting Using Artificial Neural Networks: A Predictive System Based on Country, Date, and Time Inputs

## **Project Overview**
<br>
This project explores the use of Artificial Neural Networks (ANN) for weather prediction by learning complex relationships between geographical and time-dependent weather data. The goal is to develop a data-driven forecasting approach capable of accounting for differences between countries and changes in weather conditions over time.
<br>
The project uses a large-scale weather dataset containing country, date, and time information as key input parameters. An ANN model is developed to learn patterns within the historical data and predict important weather attributes, including temperature, humidity, and feels-like temperature across different geographical regions.
<br>
A major focus of the project is addressing the challenges associated with weather data, where conditions can vary significantly according to location, season, date, and time. Instead of relying solely on traditional relationships between individual weather variables, the neural network is used to identify non-linear patterns and interactions within the dataset.
<br>
The workflow includes data preparation, feature selection, model development, training, and performance evaluation. The trained ANN is evaluated based on its ability to predict weather conditions across different regions and temporal settings.
<br>
The results demonstrate the potential of ANN-based models for producing more accurate and reliable weather predictions while maintaining the flexibility to work with large and geographically diverse datasets. The project provides an example of how machine learning and neural networks can be applied to real-world forecasting problems and establishes a foundation for further development of scalable weather prediction systems.
