# Automobile Workshop Facility Planning

A conceptual workshop layout developed through industrial facility-planning methods.

## Objective

Plan a functional facility around workflow, capacity, accessibility, and space constraints.

## Approach

1. Compare location and facility alternatives.
2. Arrange equipment, work areas, circulation, and supporting spaces.
3. Develop a 2D layout and examine alternative arrangements before implementation.
