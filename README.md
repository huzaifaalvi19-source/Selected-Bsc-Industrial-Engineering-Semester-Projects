# Selected Industrial Engineering Projects

Coursework projects from my BSc in Industrial Engineering at **University of Engineering and Technology, Taxila, Pakistan**.

This collection shows how I apply engineering analysis to production systems, manufacturing processes, facility planning, data, and human factors.
