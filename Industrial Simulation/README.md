# Cylinder-Body Manufacturing Simulation

A discrete-event simulation study of cylinder-body production at Ravi Autos, Sheikhupura.

## Objective

Represent process variability and examine opportunities to improve manufacturing-system performance.

## Approach

1. Build the production model in Arena.
2. Analyze input data and fit distributions with Input Analyzer.
3. Evaluate process behavior, resource use, and improvement scenarios.
