# Simulation and Optimization of Cylinder Body at Ravi Autos Shiekhupura, Lahore
# **Project Overview**
<br>
This project focuses on the simulation and optimization of a cylinder-body manufacturing system at Ravi Autos, Sheikhupura. The study examines the production and operational characteristics of the cylinder body, a critical engine component whose manufacturing performance can influence overall vehicle reliability, efficiency, and production effectiveness.
<br>
The project uses simulation modeling and optimization techniques to analyze the existing system and identify opportunities for improving its performance. The simulation model was developed using Arena Simulation Software, allowing the manufacturing process and associated system behavior to be represented and evaluated under different operating conditions.
<br>
To support the simulation study, Input Analyzer was used to analyze input data and determine appropriate probability distributions for the simulation model. This provided a statistical foundation for representing the variability present in the manufacturing process and improving the reliability of the simulation results.
<br>
The study examines the system with the objective of identifying improvements related to process performance, resource utilization, operational efficiency, and overall system behavior. Simulation-based analysis provides an opportunity to evaluate potential changes virtually before implementing them in the actual manufacturing environment.
<br>
The project demonstrates the application of discrete-event simulation, input-data analysis, process modeling, and optimization to a real-world automotive manufacturing system. The approach provides a framework for analyzing manufacturing operations, identifying bottlenecks and inefficiencies, and supporting data-driven decisions for process improvement.
