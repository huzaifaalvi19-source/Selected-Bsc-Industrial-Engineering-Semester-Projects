# Hand Anthropometry and Grip Strength

An ergonomics study using hand measurements and grip-strength observations from approximately 50 university students.

## Objective

Explore associations between hand dimensions and grip strength in the study sample.

## Approach

1. Measure hand, palm, finger, and body dimensions.
2. Record right-hand grip strength using a dynamometer at three settings.
3. Summarize the data and examine correlations and charts in Excel.

## Project evidence

[Read the project report](Hfe%20Report.pdf)

The analysis describes associations within the collected sample; it does not establish causation or population-wide conclusions.
